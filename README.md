# 🪙 RAP Recycle Profit Calculator
*(Sniper Arena Skin Recycle & Trade Profit Calculator)*

An offline desktop and mobile profit calculator designed for calculating profits when recycling in-game items and skins with **RAP** currency. Includes an intelligent **Target Finder**, calculation **History**, and a dual-tax **Trade Mode** calculator.

---

## 🖥️ 1. Desktop Usage (Windows)

You can launch and use the calculator on PC/Laptop in two convenient ways:

### A. Standalone Desktop App (*Recommended*)
1. Click the green **Code** button at the top of this GitHub page ➔ select **Download ZIP** and extract the folder.
2. Double-click `Launch_App.bat`.
3. The application will launch directly in a dedicated **standalone desktop app window** without browser address bars, offering a clean, modern, and responsive dark-mode interface.

### B. Web Browser Mode
* Open `index.html` with any modern web browser (Google Chrome, Microsoft Edge, Opera, Mozilla Firefox).

---

## 📱 2. Mobile Usage (Android & iOS)

Two options are available for mobile devices:

### A. Android Native App (.APK)
1. Transfer the `.apk` installer file from this repository to your Android device.
2. Open the `.apk` file on your phone and tap **Install**.
3. The app will be installed on your home screen and operates **100% offline** anytime.

### B. Mobile Browser / PWA (Progressive Web App)
1. Open `index.html` in your mobile browser (Google Chrome on Android or Safari on iOS).
2. Tap the browser menu (**⋮** on Chrome or the **Share** button on Safari) ➔ select **"Add to Home screen"** or **"Install App"**.
3. The calculator will install as a standalone fullscreen app on your device.

## 📐 Calculation Formulas & Features

### 1. Normal Mode (7% Recycle Tax)
Used when you recycle items directly on your own account:
$$\text{Net Received} = \text{Recycle Price} \times (1 - 0.07)$$
$$\text{Net Profit} = \text{Net Received} - \text{Buy Cost}$$

### 2. Trade Mode (7% Recycle Tax + 5% Trade Tax)
Used when delegating items to another player to recycle, who then transfers the RAP back to you via in-game Trade:
$$\text{After Recycle} = \text{Recycle Price} \times (1 - 0.07)$$
$$\text{Net Received} = \text{After Recycle} \times (1 - 0.05)$$
$$\text{Net Profit} = \text{Net Received} - \text{Buy Cost}$$

### 3. Key Features:
* **🧮 Calculator:** Calculates gross recycle amount, recycle tax (-7%), trade tax (-5%), break-even buy price, profit margin %, and ROI %.
* **🎯 Target Finder:** Calculates exact and range recommended buying prices based on your target profit goals (e.g., target profit `+1.5k ~ +3k RAP`).
* **📜 History:** Persists all calculation records locally with cumulative total profit tracking and a one-click *Export TXT* feature.
